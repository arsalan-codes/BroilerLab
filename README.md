## What is this? | این پروژه چیست؟

An exact browser port of a validated Python simulator of an **RFID wing-tag + dual load-cell feeding station** for industrial broilers. Every feeder visit is generated by a visit-based engine calibrated on official breeder catalogs and peer-reviewed RFID studies, then serialized to the project's 12-column device schema (3 rows per visit).

شبیه‌ساز دقیقِ مرورگریِ یک دستگاه پایش مصرف خوراک (پلاک RFID بال + دو لودسل) برای جوجه‌های گوشتی صنعتی. هر وعده توسط موتور وعده‌محور کالیبره روی کاتالوگ‌های رسمی و مقالات RFID تولید و در قالب ۱۲ستونه دستگاه ثبت می‌شود (۳ ردیف به‌ازای هر وعده).

## Features | امکانات

- 📊 **Validation dashboard** — full-cycle run reconciled daily against the active catalog (weight MAE ≈ 1–2%)
- 🧪 **Trial designer** — pens × birds × treatments (control / probiotic / growth promoter / vaccine / low-protein / heat stress), randomized blocking for fair comparisons, saved locally
- 🗺️ **Animated farm map** — every chick carries its unique tag (`B001…`) and is driven by real engine visits; per-bird inspector (BW vs sex-specific PO, cumulative intake, individual FCR, status)
- 📐 **Biostatistics lab** — pen = experimental unit; mean±SD/SE, 95% CI, one-way ANOVA + η², pairwise Welch-t with Holm correction (*, **, ***)
- ⚙️ **Live device stream** — moment-by-moment replay of the raw CSV schema with animated device panel
- 🌡️ **Scenario lab** — paired-seed heat-stress waves & second-station trials
- 📤 **Exports** — formatted Excel workbook (5 sheets incl. per-bird records) + raw CSV, generated fully client-side (zero-dependency XLSX writer)
- 🌐 **FA/EN** — complete bidirectional interface with proper Unicode bidi isolation

## The device model | مدل دستگاه

```
wing RFID ──▶ identity (99.6% read rate, RSSI −65±5 dBm)
load cell ① ─▶ platform scale   raw σ≈4g → EMA → weight_g
load cell ② ─▶ 25kg feed bin    Δmass = intake, auto-refill @3kg
queue logic ─▶ single head-hole, wait ≤90s else co-feeding event
```

Each visit emits exactly 3 rows: `timestamp,flock_id,bird_id,sensor_id,age_day,raw_weight_g,weight_g,feed_bin_kg,feed_delta_g,temp_c,humidity,rssi`

## Run locally | اجرای محلی

```bash
# no build step — any static server works
cd BroilerLab
python3 -m http.server 8300
# open http://localhost:8300
```

Or simply open `index.html` directly — everything is inline/offline.

## Regenerate reference data | بازتولید داده مرجع

```bash
python3 simulator.py   # writes output/sensor_data.csv (~364k rows), summaries & charts
python3 checks.py      # integrity checks
```
